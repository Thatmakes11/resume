% ==================== 项目与工程经历 ====================
\section{项目与工程经历}

\noindent
\textbf{基于 GRPO 强化学习的多模态 GUI Agent 推理增强} \hfill 个人项目
\begin{itemize}
    \item \textbf{多粒度数据构建与动态筛选:} 整合 OS-Atlas 等开源数据集，收集横跨多终端（Windows, Mac, Android, Web）的 14M Low Level 与 30K High Level 指令数据。利用 MLLM 实施 10 轮 Zero-Shot 启发式过滤，剔除极端难度（全对或全错）样本，最终按照难度均衡原则重采样构建 3K 规模的高质量训练集
    \item \textbf{GRPO 强化学习训练:} 针对 GUI Agent 的逻辑推理需求，基于 MLLM 引入 GRPO 算法进行 RL 微调。设计 Few-shot Prompt 引导模型显式输出思考过程，并严格规范化结构化输出（Action, Click Point, Input Text）
    \item \textbf{复合奖励函数设计与评估:} 构建基于任务执行的四种奖励：(1) 严格校验输出格式是否符合要求；(2) 预设 Action 类别精准匹配；(3) 空间坐标约束（计算点距阈值或 Bounding Box 包含关系）；(4) 生成文本与 GT 的 F1 Score 阈值评估。最终强化学习模型的准确率在各项 GUI benchmark 中均显著优于预训练及 SFT Baseline
\end{itemize}

\vspace{0.3em}
\noindent
\textbf{多模态大模型 Prefilling 阶段视觉 Token 动态压缩} \hfill 个人项目
\begin{itemize}
    \item \textbf{特征融合与动态剪枝:} 针对长视觉序列推理延迟问题，在指令序列尾部引入 Learnable Token，于 Decoder 中后期提取其与视觉 Token 的注意力权重作为先验重要性分数。随后以视觉编码器提取的多尺度特征为条件，构建 Conditioned Self-Attention 模块（在 $Q, K$ 矩阵上拼接视觉特征）对先验分数进行二次提炼，经多头平均计算最终重要性得分，实现自适应剪枝
    \item \textbf{低成本的参数高效训练:} 冻结大模型主干网络，仅训练新增的 Token 及 Attention 层，大幅降低训练开销。训练阶段除语言建模（LM）损失外，引入 Bounding Box 区域内的 Mask 作为重要性分数的监督信号，并结合 DICE、BCE Loss 与 L1 正则化进行联合优化，提升剪枝掩码的准确度
    \item \textbf{推理策略与工程评估:} 推理阶段采用 Top-K 掩码机制，固定保留得分最高的前 1/9 视觉 Token，以保障 9x 的固定压缩率。在 Visual CoT Benchmark 测试中，仅使用少量样本（20K）微调后，平均性能较 Baseline 损耗低于 10\%
\end{itemize}
