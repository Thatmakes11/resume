\section{项目与工程经历}

\noindent
\textbf{MLLM Prefilling 阶段视觉 Token 压缩} \hfill 个人项目
\begin{itemize}
    \item \textbf{特征融合与动态剪枝:} 在输入序列的尾部追加特定 Token（而不是常见的最后一个 Instruction Token），于 Decoder 中后期（约 2/3 层级）计算其与视觉 Token 的 Attention 权重作为先验重要性分数。以 Vision Encoder 的多层特征为条件，构建 Self-Attention 模块对先验重要性分数进行优化，具体为在 $Q, K$ 上拼接视觉特征。随后经多头平均后得到最终权重，剪枝掉低于阈值的视觉 Token
    \item \textbf{轻量化训练策略:} 冻结 MLLM 主干网络参数，仅训练新增的 Token 与 Self-Attention 层。使用被 Bounding Box 包围的 Masks 作为监督信号，结合 DICE Loss、BCE Loss 以及 L1 正则化联合优化，提升剪枝准确度
    \item \textbf{推理策略与工程评估:} 推理阶段采用 Top-K 机制，固定保留重要性得分最高的前 1/9 视觉 Tokens，以保障 9x 的固定压缩率。在 Visual CoT Benchmark 测试中，使用少量样本微调 (20K)，平均性能较 Baseline 损耗低于 10\%
\end{itemize}
